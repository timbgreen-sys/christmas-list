# Our Christmas List

A shared family gift list for Tim, Sue, Lucy, James and Albie. Tick a gift once it's bought and it drops off the list for everyone.

- **The page:** `index.html`, published with GitHub Pages.
- **The data:** the *Full list* tab of the "Christmas List 2026" Google Sheet.
- **The link between them:** `apps-script/Code.gs`, deployed from the sheet as an Apps Script web app.
